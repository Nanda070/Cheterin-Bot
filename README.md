# [Cheterin Bot & Dashboard (Cheterin)](https://cheterin.online/)

**Cheterin** — это многофункциональный Discord-бот, созданный специально для управления сервером, модерации, поддержки пользователей (тикет-система) и удобного управления через полноценный веб-дашборд.

## 🌟 Особенности и возможности бота

1. **Тикет-система (CTD)**
   - Пользователи могут создавать приватные ветки для обращения к администрации.
   - Поддержка закрытия тикетов модераторами.
   - **Авто-закрытие**: неактивные тикеты (без ответов более 48 часов) автоматически получают предупреждение и закрываются через 24 часа.

2. **Встроенный Веб-дашборд (Dashboard)**
   - Управление ботом через красивый и современный веб-интерфейс.
   - **Frontend**: React 19, Vite, Tailwind CSS 4, TypeScript.
   - **Backend**: `aiohttp` (сервер поднимается параллельно с ботом в одном процессе).
   - **Авторизация**: через Discord OAuth2.
   - Поддержка работы в режиме SPA (Single Page Application).

3. **Турнирные сетки (Brackets)**
   - Генерация турнирных сеток (Single Elimination).
   - Настройка сидирования (seeding) участников и продвижение победителей по сетке.
   - Интеграция с ивентами сервера и отображение турнирных таблиц.

4. **Конструктор сообщений (Embed Builder)**
   - Полноценный визуальный редактор прямо в веб-дашборде для создания красивых Embed-сообщений (с настройкой цветов, картинок, полей и футеров).

5. **Управление событиями и участниками**
   - **События (Events)**: управление ивентами и сбор заявок.
   - **Просмотр участников (Members)**: удобная панель в дашборде для просмотра информации по участникам сервера.

6. **Инструменты Модерации**
   - **Временные баны (Tempban)**: выдача банов на определенный срок.
   - **Режим изоляции (Lockdown)**: мгновенная блокировка (lockdown) каналов или всего сервера при рейдах/набегах.
   - **Логирование модерации**: запись всех действий администрации в отдельный лог-файл и канал.

7. **Анти-спам защита (Spam)**
   - Автоматическое обнаружение подозрительной активности и спама.
   - Оповещения в лог-каналы и выдача специальных ролей нарушителям.
   - Исключения для определенных каналов (`SPAM_EXCEPTION_CHANNELS`).

8. **Система обратной связи (Feedback)**
   - Интерактивное меню для сбора отзывов, баг-репортов и предложений от игроков.
   - Разделение фидбека по настраиваемым категориям и управление тикетами из дашборда.

9. **Управление ролями и входом**
   - **Автороли (AutoRoles)**: автоматическая выдача ролей при входе на сервер.
   - **Приветствия (Welcome)**: настройка сообщений о входе и выходе пользователей на сервер.
   - **Трекинг приглашений**: подсчет и статистика инвайтов.
   - **Выдача ролей по реакциям (Reaction Roles)**: автоматическая выдача ролей при нажатии на эмодзи.

10. **Кастомные кнопки и вебхуки**
    - Возможность создания интерактивных кнопок в каналах.
    - Отправка сообщений в каналы от имени вебхуков (с ограничением прав по ролям).

## 🛠 Технологический стек

- **Язык**: Python 3.10+
- **Библиотека Discord**: `discord.py`
- **Backend Дашборда**: `aiohttp`
- **Frontend Дашборда**: React, Vite, Tailwind CSS
- **Тестирование**: `pytest`, `vitest`
- **Хранение данных**: Локальные JSON-файлы (`config.json`, `invites_stats.json`, `events_data.json`, `brackets_data.json` и др.). Базы данных SQL не требуются, всё работает "из коробки".

## 📦 Требования

- **Python 3.10** или выше.
- **Node.js LTS** (необходим только для сборки фронтенд-дашборда).

## 🚀 Установка и запуск (Локально)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Nanda070/Cheterin_Bot_Dashboard.git
   cd Cheterin_Bot_Dashboard
   ```

2. **Установите Python-зависимости:**
   Создайте виртуальное окружение и установите библиотеки:
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Linux/macOS:
   # source venv/bin/activate
   
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения (`.env`):**
   Создайте файл `.env` в корне проекта и добавьте следующие ключи:
   ```env
   BOT_TOKEN=ВАШ_ТОКЕН_БОТА
   GUILD_ID=ID_ВАШЕГО_СЕРВЕРА
   # URL для авторизации через Discord (для локальной работы)
   DISCORD_OAUTH_REDIRECT_URI=http://localhost:8080/api/auth/discord/callback
   ```
   *Остальные настройки (ID каналов, ролей) сохраняются в `config.json` и могут быть настроены через панель "Config" в дашборде (или `bot_config.py`).*

4. **Соберите фронтенд дашборда:**
   ```bash
   cd dashboard/frontend
   npm install
   npm run build
   cd ../..
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```
   При запуске скрипта `main.py` будут одновременно запущены Discord-бот и веб-сервер дашборда на порту `8080` (по умолчанию).

## 🌍 Деплой на продакшен

Если вы хотите развернуть бота на полноценном VPS/VDS сервере (например, Oracle Cloud Ubuntu) с привязкой домена (например, `cheterin.online`), HTTPS-сертификатами и фоновым режимом работы, **обязательно ознакомьтесь с файлом [DEPLOY.md](DEPLOY.md)**.

В инструкции по деплою расписаны:
- Настройка DNS-записей и Firewall (UFW).
- Установка системных зависимостей (Nginx, Certbot, Python, Node.js).
- Сборка продакшен версии фронтенда (`DASHBOARD_FRONTEND_DIST`).
- Настройка Nginx в качестве reverse-proxy.
- Запуск бота в фоновой сессии через `tmux`.

## 📁 Структура проекта

- `main.py` — Точка входа. Инициализирует бота и поднимает aiohttp-бекенд дашборда.
- `bot_config.py` — Логика загрузки и сохранения настроек в `config.json`.
- `dashboard/` — Директория веб-дашборда.
  - `backend/` — API и маршруты для авторизации/данных.
  - `frontend/` — Исходный код React SPA-приложения с различными панелями (Events, Members, Brackets, Embed Builder и т.д.).
- **Коги (Cogs / Модули бота)**:
  - `memobb.py` — Тикет-система (CTD).
  - `spam.py` — Система анти-спама.
  - `lockdown.py`, `tempban.py` — Команды модерации.
  - `welcome.py`, `events.py` — Обработка входов/выходов и основных событий.
  - `feedback_menu.py`, `button.py`, `reaction_roles.py` — Интерактивные элементы интерфейса Discord.
  - `brackets.py` — Логика генерации турнирных сеток.
  - `embed_builder.py` — Инструментарий для сборки Embed-ов.
