## Зачем Cheterin

Один бот вместо десятка разрозненных утилит. Админы настраивают модули в браузере — участники просто пользуются командами в Discord.

| | |
|:---|:---|
| **Модерация** | Логи, антиспам, автомод, верификация, антирейд, варны |
| **Сообщество** | Уровни и XP, приветствия, инвайты, sticky-роли, дни рождения |
| **Экономика** | Валюта сервера, магазин, daily, казино |
| **Игры** | Семья и поставки (GTA5RP), ValChecker (Valorant) |
| **Развлечения** | Wordle, рулетка, Мафия, Бункер, Relations |
| **Контент** | События, розыгрыши, опросы, эмбеды, стримы |

На сервере: **`/help`** — короткая справка.  
Статус бота: `Playing /help • Cheterin`.

---

## С чего начать

1. Добавьте бота на сервер через [cheterin.online](https://cheterin.online).
2. Войдите в панель тем же Discord-аккаунтом.
3. Выберите сервер и включите нужные модули.
4. Подробности по каждому разделу — в [документации](https://cheterin.online/docs).

Поддержка и сообщество: **[Cheterin Group](https://discord.gg/cheterin)**.
