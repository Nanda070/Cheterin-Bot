# Cheterin — Discord-бот и веб-дашборд

**Cheterin** — многофункциональный Discord-бот для игровых сообществ с полноценной веб-панелью управления. Модерация, система уровней, тикеты, приватные голосовые комнаты, турниры, стрим-уведомления — всё настраивается через браузер, без команд в чате.

Полная документация доступна на публичной странице сайта: `/docs` (разделы «Условия пользования» и «Политика конфиденциальности» — `/terms` и `/privacy`).

## 🌟 Возможности

### Активность и рейтинг
- **Система уровней (XP)** — опыт за текстовые сообщения (15–25 XP, раз в минуту) и голосовую активность (только «активным», минимум двое в канале, накопительный множитель). Два трека наград-ролей: за уровень и за суммарное время в войсе. Команда `/ранг` с генерируемой PNG-карточкой (кастомный фон), лидерборд в дашборде и публичный `/leaderboard`.
- **Статистика войса** — активность по часам и дням недели, топ каналов и участников, суммарные показатели за период.

### Модерация и безопасность
- **Анти-спам** — обнаружение флуда, удаление сообщений, авто-наказание, кнопки Ban/Оставить в лог-канале.
- **Tempban** — временные баны с автоматическим разбаном.
- **Lockdown** — экстренная изоляция сервера при рейде с бэкапом и восстановлением прав ролей.
- **Тотальное логирование** — 20+ типов событий (сообщения, войс, роли, каналы, баны, ники, инвайты, эмодзи), каждый со своим тумблером и каналом.
- **Аудит дашборда** — каждое действие модератора в панели записывается: кто, что, когда.

### Сообщество
- **Тикеты CTD** — приватные ветки поддержки с авто-закрытием неактивных (48ч + 24ч).
- **Обратная связь** — заявки по настраиваемым категориям с решениями модераторов.
- **События и голосования** — кнопки участия, роли-награды.
- **Турнирные сетки** — Single Elimination, Double Elimination и Round Robin, публичные ссылки для зрителей.
- **Поставки** — сборы участников с резервным списком, напоминаниями и статистикой посещений.
- **Приватные голосовые комнаты** — вход в лобби создаёт личную комнату; панель управления с кнопками (доступы, лимит, передача, мут); восстановление после рестарта.

### Контент и интеграции
- **Embed Builder** — визуальный конструктор эмбедов с шаблонами и интерактивными кнопками-формами.
- **Роли по реакциям**, **авто-роли**, **приветствия** (канал + DM-гайд новичку), **статистика приглашений**.
- **Публикации и подписки** — уведомления о стримах Twitch (Helix API) и новых видео YouTube (RSS), с шаблонами сообщений, ключевыми словами и защитой от повторов.
- **Ретрансляция новостей** — зеркалирование сообщений ботов с сервера-источника.
- **Массовая выдача ролей** — фоновые задачи с отчётом.

### Дашборд
- **Frontend:** React 19, Vite, Tailwind CSS 4, TypeScript.
- **Backend:** `aiohttp` — поднимается в одном процессе с ботом.
- **Авторизация:** Discord OAuth2, доступ по ролям, проверка на каждом запросе.
- Публичные страницы без авторизации: документация, условия, приватность, сетки, лидерборд.

## 🚀 Быстрый старт

Требования: **Python 3.10+** (рекомендуется 3.11) и **Node.js LTS**.

```bash
git clone https://github.com/Nanda070/Cheterin_Bot_Dashboard.git
cd Cheterin_Bot_Dashboard
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Создайте `.env`:

```env
BOT_TOKEN=токен_бота
GUILD_ID=ID_сервера
DISCORD_CLIENT_ID=ID_приложения
DISCORD_CLIENT_SECRET=секрет_приложения
DISCORD_OAUTH_REDIRECT_URI=http://localhost:8080/api/auth/discord/callback
DASHBOARD_SESSION_SECRET=случайная_строка_32+_символа
DASHBOARD_ACCESS_ROLE_IDS=ID_ролей_с_доступом_через_запятую

# Опционально — стрим-уведомления Twitch
TWITCH_CLIENT_ID=...
TWITCH_CLIENT_SECRET=...
```

> В Discord Developer Portal включите интенты **Server Members** и **Message Content** и добавьте redirect URI в OAuth2 → Redirects.

Соберите фронтенд и запустите:

```bash
cd dashboard/frontend && npm install && npm run build && cd ../..
python main.py
```

Панель будет доступна на `http://localhost:8080`.

## 🗂 Хранение данных

Всё локально — JSON-файлы и SQLite (`stats.db` — рейтинг, войс-сессии, аудит; `private_rooms.db` — приватные комнаты). Внешние базы и облачные сервисы не используются. Полный список файлов — в разделе документации «Для разработчиков».

## 📚 Команды бота

| Команда | Описание |
|---|---|
| `/ctd_setup` | Развернуть панель тикетов CTD |
| `/antispam` | Включить/выключить антиспам-режим (Lockdown) |
| `/userinfo` | Сводка по участнику |
| `/реаки-поставка` | Создать сбор на поставку |
| `/ранг` | Карточка ранга с уровнем и прогрессом |

Остальное управление — через дашборд.
